# Словник вимови (оновлюється з кожним відео)

Наголос ставимо символом U+0301 після голосної. Текст для синтезу — малими літерами, числа словами.

| Слово / фраза | Як писати для голосу | Примітка |
|---|---|---|
| порівнюй | `порі́внюй,` (з комою після) | без коми зливається з наступним словом |
| порівняй | `порівняй` (без наголосу) | з наголосом гірше |
| гірший | ❌ уникати → `невигідний` (без наголосу) | розпізнається як «їрший/єрший» |
| нуль | `нуль злотих …` | окремо звучить як «ноль» |
| стресу | `— без стре́су!` (тире + знак оклику) | інакше «трасу/страсу» |
| знайомо? | ❌ уникати → `знайо́ма ситуа́ція?` | коротке слово окремо невиразне |
| перше | `пе́рше: диви́сь на …` | |
| друге | `друге: порівняй два або три сервіси.` | «два-три» краще як «два або три» |
| третє | `тре́тє` | інколи звучить як «третье» — прийнятно, стежимо |
| скільки | `скі́льки` після крапки або двокрапки | |
| 2–3, цифри | писати словами | |
| UKR | `у ка ер` | ASR пише «УКР» — ок |
| CUKR | `цукр` | |
| MOS | `мос` | ASR пише «МОЗ» — звучить правильно |
| 800+ | `ві́сімсот плюс` | |
| 4 березня 2027 | `четве́рте бе́резня два́дцять сьо́мого` | |
| для всієї сім'ї | `для всіє́ї сім'ї́` | «усієї» гірше; апостроф працює |
| перше (перед дієсловом) | `пе́рше — переві́р…` (тире) | з двокрапкою інколи «першет» |
| є (на початку речення) | `є ка́рта…` | інколи чується «я» — стежимо |

**Довжина:** якщо відео > 40 с — atempo 1.05 (без зміни тембру), паузи 0.15/0.2 с.
**QA-референс:** порівнювати з субтитрами, де абревіатури замінені на вимову (UKR→укр, MOS→мос, 800+→800 плюс).

## Правила субтитрів (з QA відео 02)
- Субтитри ділимо ВРУЧНУ символом `|` у тексті субтитрів (не розривати «крок за кроком», «статус UKR», «до 4 березня», число + слово).
- Без тире на початку/в кінці рядка.
- Безпечні зони 1080×1920: верх 0–140, праві кнопки x>930 при y 700–1520, низ y>1520. Субтитри: центр x=515, ширина ≤780, y≈1240, на напівпрозорій темній плашці.
- Картки/плашки: x від 60 до 900 максимум.
