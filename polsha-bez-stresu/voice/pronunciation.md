# Словник вимови (оновлюється з кожним відео)

Наголос ставимо символом U+0301 після голосної. Текст для синтезу — малими літерами, числа словами.

| Слово / фраза | Як писати для голосу | Примітка |
|---|---|---|
| порівнюй | `порі́внюй,` (з комою після) | без коми зливається з наступним словом |
| порівняй | `порівняй` (без наголосу) | з наголосом гірше |
| гірший | ❌ уникати → `невигідний` (без наголосу) | розпізнається як «їрший/єрший» |
| нуль | `нуль злотих …` | окремо звучить як «ноль» |
| стресу | `— без стре́су!` (тире + знак оклику) | інакше «трасу/страсу» |
| знайомо? | ❌ уникати → `знайо́ма ситуа́ція?` | коротке слово окремо невиразне |
| перше | `пе́рше: диви́сь на …` | |
| друге | `друге: порівняй два або три сервіси.` | «два-три» краще як «два або три» |
| третє | `тре́тє` | інколи звучить як «третье» — прийнятно, стежимо |
| скільки | `скі́льки` після крапки або двокрапки | |
| 2–3, цифри | писати словами | |
