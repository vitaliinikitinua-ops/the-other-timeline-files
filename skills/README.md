# Скіли каналу The Other Timeline

| Скіл | Для чого |
|---|---|
| `channel-analyst` | Аналіз будь-якого каналу за посиланням, розбір відео як експерт, ідеї наступних відео |
| `finance-timeline-studio` | Фінансові "What IF" відео кодом: реальні дані, Piper-голос, Shorts, українська доріжка |
| `episode-qa` | Самоперевірка кожного відео перед публікацією (цифри, кадри, звук, розмір, мініатюри) |
| `youtube-publisher` | Публікація і планування через Zapier з урахуванням лімітів |

Вже є в claude.ai: `other-timeline-studio` (стиль, персонаж, ElevenLabs), `story-shorts-studio` (Shorts).

Встановлення: claude.ai у браузері → Settings → Capabilities → Skills → Upload skill → вибрати .zip → увімкнути.
