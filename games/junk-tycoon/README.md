# Junk Lot Tycoon — prototype v0.1 (Little Loop Games)
First-person 3D (three.js 0.160.0, vendored, MIT). Open index.html through any web server.
Design doc: DESIGN_DOC.md. Data/balance: data.js. Game: game.js.
Prototype covers: lots board (Grandma's Garage, Student Storage), garage door reveal, carrying items,
workbench scrubbing (condition 0-100% -> price), rare hidden items, trash recycling, shop tables + customers,
5 upgrades, 9 achievements, localStorage save of money/upgrades/achievements.
