# Bean Baron — coffee tycoon (idle) · studio brand: Little Loop Games

- Core loop (10 s): tap "Serve" / watch customers buy -> coins fly up -> number goes up.
- Session loop (5-15 min): buy stations (drip coffee -> espresso bar -> pastry case -> ... -> roastery) and
  one-off upgrades -> income jumps -> next station unlocks.
- Meta loop (days): "Open a new café" (prestige) -> Stars = permanent +income -> come back tomorrow for
  offline earnings and the daily reward streak.
- Fantasy: from one coffee cart to a coffee empire.

Targets: first buy < 15 s; something new every 30-90 s in the first 10 min; first prestige 30-60 min;
second run ~2x faster; offline cap 4 h at 50% (rewarded ad doubles it); ads never required.
Monetization: GameDistribution first (SDK, revenue share from day one), CrazyGames build later.
