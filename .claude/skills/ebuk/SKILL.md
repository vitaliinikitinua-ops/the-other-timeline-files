# Новий е-бук — «Польща без стресу»

Мова — українська. Продукт має **вирішувати конкретні проблеми** практично: чеклісти, кроки, шаблони, без «води».

## Крок 1. Питання (AskUserQuestion, 3–4 питання)
1. Тема і головна проблема читача (запропонуй 3 варіанти).
2. Для кого (новоприбулі / працюючі / сім'ї з дітьми / JDG).
3. Обсяг і формат (міні-гайд 15–20 с. / повний 40–60 с.; + шаблони/чеклісти).
4. Ціна (29 / 49 / 79 zł) і чи буде розділ з партнерськими посиланнями (з позначкою реклами).

## Крок 2. Дослідження і план
- Зміст по розділах: проблема → покрокове рішення → чекліст → типові помилки.
- Факти лише з офіційних джерел (gov.pl, ZUS, NFZ, podatki.gov.pl), дата актуальності на кожній сторінці, примітка «не є юридичною консультацією».
- Покажи план користувачу на затвердження.

## Крок 3. Написання і верстка
- PDF A4 з охайним дизайном (бренд «Польща без стресу»), клікабельний зміст, чеклісти для друку.
- Перевір усі посилання і цифри ще раз перед здачею.

## Крок 4. Продаж
- Опис для Naffy (заголовок, для кого, що всередині, ціна), обкладинка, 3 картинки-превʼю.
- Після публікації — запропонуй 3–5 відео-анонсів (через скіл nove-video).
- Не публікуй і нічого не купуй без явного «так» від користувача.
