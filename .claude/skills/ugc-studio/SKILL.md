# UGC Studio

Пайплайн і код: `UGC_CREATOR/` (див. `UGC_CREATOR/README.md`). Монтаж: `python3 UGC_CREATOR/scripts/ugc_build.py <project.json>`.

## Правила спілкування
- **Завжди українською.**
- **Інтерв'ю — тільки через інструмент AskUserQuestion** (клікабельні варіанти), не текстом у чаті.
  До 4 питань за раз, у кожному 2–4 варіанти, рекомендований — першим із позначкою "(рекомендовано)".
  Користувач може обрати "Other", щоб написати своє.
- Не перевантажувати технічними питаннями; якщо не знає — рекомендувати найкраще.

## Бюджет $0 (критично)
- Нічого не купувати, не витрачати кредити Higgsfield / ElevenLabs понад безкоштовні ліміти без явного дозволу.
- Higgsfield: 0 кредитів (≈70 кредитів за 10 с Seedance 720p) — лише оцінка вартості, без генерації.
- ElevenLabs free: ~10 000 символів/міс — перевіряти `account_get_usage` перед використанням.
- Безкоштовний голос: Piper `uk_UA-tetiana-high` (найкраща вимова серед Piper; інші голоси Piper спотворюють слова).
- Edge-TTS у хмарному середовищі НЕ працює (проксі блокує WebSocket).

## Обраний робочий процес (варіант 1)
Модель **знімає себе на телефон** за планом зйомки, Claude робить усе інше. Без AI-генерації обличчя
(немає ризику «іншої людини», не потрібне маркування AI-контенту).
Якщо голос синтезований, а вона говорить у кадрі — спершу генерувати озвучку, вона беззвучно
проговорює текст під неї (playback), щоб губи збігались.

## Порядок роботи для кожного відео
1. **Аналіз продукту** → `projects/<id>/research/product_facts.md`: лише перевірені факти з офіційного
   джерела; розділи «перевірено / офіційні обмеження / заборонено».
2. **Інтерв'ю (AskUserQuestion)**: мета, стиль (Natural / Premium / TikTok Sales / мікс), локація,
   одяг, зачіска/макіяж, подача (в камеру / демонстрація), голос (її / синтез), ракурс, настрій,
   перші 3 секунди, CTA, музика, варіації. Відповіді → `projects/<id>/brief.json`.
3. **Сценарій** українською розмовною мовою: HOOK 0–3 с, PROBLEM 3–10, PRODUCT 10–23, BENEFITS 23–32,
   CTA 32–40. Показати користувачу, дочекатися затвердження. + 3 альтернативні хуки.
4. **План зйомки** (шот-лист): кожен кадр — що робить, що каже, ракурс, тривалість, підказки
   (вертикально, 1080p/4K 30fps, світло з вікна, задня камера якщо можливо, тиша для звуку).
5. **Монтаж**: кліпи → `raw_footage/`, заповнити `project.json`, запустити `ugc_build.py`.
6. **QC**: автоматичний звіт + переглянути кадри (контакт-лист), перевірити субтитри зі сценарієм.
7. **Здача**: MP4, сценарій, список сцен, SRT, мініатюра, 3 хуки, підпис TikTok, підпис Instagram,
   хештеги, QC-звіт. Нічого не публікувати автоматично.

## Комплаєнс для дієтичних продуктів
Ніколи: гарантоване схуднення, «мінус N кг», до/після, вигадані відгуки/дослідження, медичні заяви,
«модель схудла на цьому» (якщо не правда), «без цукру» якщо цукор є в складі.
Для замінників їжі — згадувати «в межах низькокалорійного харчування».

## Постійна модель
Фото-референси: `UGC_CREATOR/references/model/` (у .gitignore — не комітити, не змінювати).
Постійний образ (за замовчуванням): високий хвіст, природний денний макіяж, чорний жакет + біла футболка.
